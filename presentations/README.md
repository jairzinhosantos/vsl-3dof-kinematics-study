# Presentation outline

Material de apoyo aún no exportado a PPT. El objetivo es entender y explicar; generar diapositivas sólo cuando el grupo necesite ensayar o entregar.

1. Pregunta, robot real y alcance provisional.
2. Esquema y convenciones comunes.
3. Directa e inversa: ejemplo y reconstrucción.
4. Diferencial: de qdot a v, columnas del Jacobiano.
5. Singularidades: tarea de posición, caso y consecuencias.
6. Control: trayectoria deseada, seguimiento, error y límites.
7. Construcción virtual y procedencia de la animación.
8. Resultados propios, incertidumbres y conclusiones.

Cada integrante propone una figura y su explicación. No presentar como resultados los bloques aún pendientes. Confirmar duración de exposición antes de fijar número final de slides.
