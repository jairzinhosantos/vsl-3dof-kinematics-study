# Optional MATLAB adapter

Conserva el código inicial, sin ejecución MATLAB verificada. Python es el entorno principal aceptado según la aclaración del equipo. No hace falta ejecutar este adaptador para avanzar con los experimentos Python.

Desde la raíz del repositorio: `addpath('adapters/matlab/tests'); verify_model;` y `addpath('adapters/matlab/simulations'); simulate_differential;`. Las salidas se escriben en `outputs/matlab`. No atribuir resultados Python a este adaptador.
