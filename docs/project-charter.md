# Project charter

## Propósito

Desarrollar y explicar la cinemática directa, inversa y diferencial, las singularidades y el control cinemático de un robot antropomórfico real de 3 GDL. La geometría se toma del artículo VSL de Ramzy et al. (2024).

## Alcance inicial

Se modela la geometría rígida nominal y se simula movimiento prescrito. Se verificarán los cinco temas con escenarios reproducibles. La vista 3D consume las posiciones del mismo modelo Python. La decisión docente sobre la aproximación rígida puede exigir modificar el alcance.

No se presenta la visualización como validación experimental, réplica dinámica VSL o construcción física. Los datos dummy prueban el sistema de cálculo y visualización; no sustituyen evidencia experimental.

## Criterio para Review

Cada bloque debe tener explicación, ecuaciones y supuestos, implementación cuando corresponda, protocolo, evidencia y limitaciones. La integración del informe requiere revisión de Jairzinho y aportes auténticos de los integrantes. Las pruebas correctas no constituyen aprobación del equipo ni del docente.
